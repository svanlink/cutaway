# Detecting work and projects: what the best trackers do
*Generated 2026-09-05 | Sources: 70 | Confidence: high on permissions, idle logic and Resolve API; medium on Adobe title formats (undocumented by Adobe); low where marked "insufficient data"*

## Executive summary

- Every strong tracker samples the active window (Timing 1 Hz, Qbserve 3 s), reads app + title via Accessibility, and layers per-app document paths on top through AppleScript/JXA. None reads pixels by default; Timing falls back to Screen Recording only for apps that hide titles from AX, naming Premiere Pro ([Timing FAQ](https://timingapp.com/help/faq)).
- Permissions asked: Accessibility (all), Automation per app (Timing, RescueTime), Screen Recording only for opt-in features (Timing, Rize). The explanation is always one sentence: reads window titles, never controls the Mac, never keystrokes ([RescueTime](https://help.rescuetime.com/article/59-how-do-i-enable-accessibility-permissions-on-mac-osx), [Rize](https://rize.io/blog/what-rize-tracks-and-what-it-never-sees)).
- Adobe: After Effects (`DoScript` → `app.project.file`), Photoshop and Illustrator (`name of current document`) and InDesign (`full name`) expose the current document to AppleScript. Premiere Pro exposes nothing and hides its title from AX; only a UXP/CEP panel or Screen Recording reaches it.
- Resolve: external scripting is Studio-only since 19.1 (Nov 2024); 20.x–21.0.4 only added API. Cutaway's Tier 1/Tier 2 split is right.
- Idle defaults cluster at 3–5 min (Timing 3, ActivityWatch 3, RescueTime 5, Rize 5). Over-billing is avoided by subtracting idle retroactively, prompting with explicit discard/keep/assign choices, and exempting media via OS signals (display-sleep assertion, audible tab). No surveyed tracker uses render CPU (insufficient data).
- Energy/privacy: Apple says subscribe, don't poll; `NSWorkspace` and `AXObserver` notifications replace most polling. Refuse Screen Recording: it gates `kCGWindowName`, triggers Sequoia's monthly re-consent, and is being pushed to ScreenCaptureKit.

## 1. How the strongest trackers detect and classify work

**Timing.** Once per second it records the active window's title plus "document path or URL (if available)"; background apps are never recorded ([FAQ](https://timingapp.com/help/faq)). Paths come from per-app AppleScript, hence the "Timing.app wants to control Safari.app" Automation dialogs. Its compatibility table marks Final Cut Pro, Premiere, After Effects, Photoshop, Illustrator and InDesign supported; Resolve is "time spent in the app, but no project details" ([FAQ](https://timingapp.com/help/faq)). For apps hiding titles from AX (Premiere named), an off-by-default preference falls back to the CGWindow API, which "requires the Screen Recording permission … It does not record your actual screen" ([preferences](https://timingapp.com/help/preferences)). Classification is rules over Keywords, Domain, URL, File Path, Title, Application, Device, Start Time, Day of Week; new projects auto-offer a "title or path contains name" rule ([rules](https://timingapp.com/help/rules)). Cost: <0.5 % CPU, <50 MB ([FAQ](https://timingapp.com/help/faq)).

**RescueTime** needs Accessibility ("read the window titles … Without it, RescueTime can see that an app is open but not what you're doing inside it") and Automation per browser, stressing it "does not give RescueTime control of your computer" ([help](https://help.rescuetime.com/article/59-how-do-i-enable-accessibility-permissions-on-mac-osx)). Users can disable "Collect window and document titles" ([settings](https://help.rescuetime.com/article/454-configuring-your-work-settings)).

**Rize** captures "app name, window title, URL, and timestamps" and requests Accessibility plus Screen Recording ([guide](https://rize.io/guides/getting-started)); Screen Recording only powers an opt-in "Screen Text" feature requiring org, admin and member consent ([blog, Aug 2026](https://rize.io/blog/what-rize-tracks-and-what-it-never-sees)).

**ActivityWatch** polls; without Accessibility it "can only log current application, and not window title" ([README](https://github.com/activitywatch/aw-watcher-window)). It replaced `osascript` with in-process JXA, which also yields browser URLs ([PR #52](https://github.com/ActivityWatch/aw-watcher-window/pull/52)), then added a Swift non-polling watcher ([PR #68](https://github.com/ActivityWatch/aw-watcher-window/pull/68)). Its prompt is a bare `AXIsProcessTrusted()` check deep-linking to the Accessibility pane ([commit](https://github.com/ActivityWatch/aw-watcher-window/commit/c683671)); macOS "forgets" the grant after updates ([issue #60](https://github.com/ActivityWatch/aw-watcher-window/issues/60)).

**Timemator** rules (application, file, folder, window title) carry a dwell time "to prevent false triggering" and a notify-only mode ([manual](https://timemator.com/support/auto-tracking/)). **Qbserve** reads the frontmost window via AX "once every 3 seconds" and matches rules on "web page addresses, file paths, window titles, or chats" ([support](https://qotoqot.com/qbserve/support/), [work hours](https://qotoqot.com/qbserve/articles/tracking-work-hours/)).

None derives documents from `NSRunningApplication`; paths come from AppleScript or titles.

## 3. DaVinci Resolve scripting and titles, 2025-2026

- **Edition gate.** The README has always said "Scripting API for DaVinci Resolve Studio" ([README](https://github.com/deric/DaVinciResolve-API-Docs/blob/84f0a2e83e4a81c0db2197768d7cbbbe4960d0b7/README.adoc)). Since 19.1 the free edition's endpoint "refuses the connection" ([Pulse Edit](https://pulseedit.com/davinci-resolve-19-scripting-api-fix.html)); UIManager also went Studio-only, confirmed intentional by BMD's Peter Chamberlain ([r/davinciresolve](https://www.reddit.com/r/davinciresolve/comments/1gpo20i/191_broken_scripts_megathread/)). Free gets the internal Console only ([Wild Lion, Mar 2026](https://wildlion.media/davinci-resolve-python-scripting-the-complete-guide-to-the-api/)).
- **`fuscript`** ships in the bundle (present locally in 21.0.4) and runs `-l py3`/`-l lua` against `bmd.scriptapp("Resolve")` ([We Suck Less](https://www.steakunderwater.com/wesuckless/viewtopic.php?p=49594)); `scriptapp` returns `None` when Resolve is closed or no project is open ([Wild Lion](https://wildlion.media/davinci-resolve-python-scripting-the-complete-guide-to-the-api/)); external access must be Local/Network in Preferences ([README](https://resolvedevdoc.readthedocs.io/en/latest/API_intro.html)).
- **Calls.** `GetProjectManager().GetCurrentProject().GetName()`; `CreateProject(name)` returns None if not unique; `LoadProject(name)` ([README](https://github.com/diop/davinci-resolve-api/blob/master/docs/README.md), [20.0 gist](https://gist.github.com/Manouchehri/e32461dccd824167bac8358bb21c8040)).
- **Changes.** 19.1: cloud projects, mark in/out, Quick Export ([19.1](https://documents.blackmagicdesign.com/SupportNotes/DaVinci_Resolve_19_1_New_Features_Guide.pdf)); 20.1: voice isolation, JS Promises ([20.1](https://documents.blackmagicdesign.com/SupportNotes/DaVinci_Resolve_20.1_New_Features_Guide.pdf)); 20.2: set timeline/clip names ([20.2](https://documents.blackmagicdesign.com/SupportNotes/DaVinci_Resolve_20.2_New_Features_Guide.pdf)); 21 (Apr 2026): user metadata variables in scripts ([21](https://documents.blackmagicdesign.com/SupportNotes/DaVinci_Resolve_21_New_Features_Guide.pdf)); 21.0.3/21.0.4 (Jul 2026): `GetProjectAttributesInCurrentFolder()` lists name/dates/notes for every project without opening them; README dated 24 Jul 2026 ([Wild Lion, Jul 2026](https://wildlion.media/davinci-resolve-scripting-api-21-0-4/)). Python 3.10–3.12 is the stable range ([Wild Lion](https://wildlion.media/davinci-resolve-python-scripting-the-complete-guide-to-the-api/)).
- **Title.** Cutaway parses `DaVinci Resolve - <Project>` and tolerates bare `DaVinci Resolve` ([ProjectDetector.swift](https://github.com/svanlink/cutaway/blob/main/Sources/Cutaway/Detection/ProjectDetector.swift)); no BMD document specifies it, and Timing extracts nothing from Resolve ([Timing FAQ](https://timingapp.com/help/faq)). Project/Timeline Name exist only as in-app metadata variables ([Mixing Light](https://mixinglight.com/color-grading-tutorials/using-metadata-variables-in-davinci-resolve/)).

## 4. Presence/idle logic that avoids over-billing

| Product | Threshold | Media/meeting exemption | Return flow |
|---|---|---|---|
| Timing | 3 min, configurable ([FAQ](https://timingapp.com/help/faq)) | Idle detection off "when the frontmost app prevents your screen from going dark"; prompt when a video call ends ([FAQ](https://timingapp.com/help/faq), [prefs](https://timingapp.com/help/preferences)) | "What Did You Do?" only after ≥5 min, never after >10 h; timers ignore idle; "Keep the timer running" option; focus returns to previous app ([FAQ](https://timingapp.com/help/faq), [changes](https://timingapp.com/changes)) |
| RescueTime | 5 min, then "subtract those 5 minutes" ([FAQ](https://help.rescuetime.com/article/469-frequently-asked-questions)) | none | Offline prompt after 5 min default, 5–30 range ([help](https://help.rescuetime.com/article/76-how-to-record-offline-time)) |
| Rize | 5 min pause; 60 min = session end; "the same signal a screensaver uses" ([privacy](https://rize.io/privacy)) | none | auto-resume |
| ActivityWatch | 180 s, 5 s poll ([config](https://docs.activitywatch.net/en/latest/configuration.html)) | Not AFK while the active tab is audible ([FAQ](https://docs.activitywatch.net/en/latest/faq.html)); "extend timeout for mic" rejected because long meetings still flip AFK ([issue #41](https://github.com/ActivityWatch/aw-watcher-afk/issues/41)) | none |
| Qbserve | unpublished | Keeps tracking "Videos & TV" ([home](https://qotoqot.com/qbserve/)) | Suggests manual entry |
| Toggl Track | configurable | none | Discard / Discard and continue / Add as new entry / Keep ([Toggl](https://toggl.com/blog/billable-vs-non-billable)); criticised as confusing ([Grumpy Website](https://grumpy.website/page/43)) |

Two constants: idle counts from *last input*, so the stretch is removed retroactively, and prompts have a floor. Timing's display-sleep trick maps to IOKit: apps holding `kIOPMAssertionTypePreventUserIdleDisplaySleep` (players, meeting apps) are visible system-wide ([Apple](https://developer.apple.com/documentation/iokit/iopmlib_h/iopmassertiontypes)). Render-CPU exemptions: insufficient data.

## 5. Energy and privacy costs

- **Polling vs notifications.** Apple: "Polling wastes a significant amount of CPU time … Register to receive these notifications" ([Apple HIG](https://leopard-adc.pepas.com/documentation/UserExperience/Conceptual/AppleHIGuidelines/XHIGCharGreatSoftware/XHIGCharGreatSoftware.html)). `NSWorkspace.didActivateApplicationNotification` delivers app switches with the `NSRunningApplication` ([Apple](https://developer.apple.com/documentation/appkit/nsworkspace/didactivateapplicationnotification)); `frontmostApplication` is KVO-compliant ([Apple](https://developer.apple.com/documentation/appkit/nsworkspace/frontmostapplication)). `AXObserverAddNotification` on the app element (`kAXFocusedWindowChanged`) and focused window (`kAXTitleChanged`) replaces title polling; the system-wide element cannot be observed ([Apple](https://developer.apple.com/documentation/applicationservices/1462089-axobserveraddnotification)). Karabiner re-subscribes the title notification on every focus change ([Karabiner](https://github.com/tekezo/Karabiner/blob/master/src/util/AXNotifier/Karabiner_AXNotifier/Classes/AXApplicationObserver.m)). Remaining timers should carry ≥10 % tolerance for coalescing ([Apple](https://developer.apple.com/documentation/foundation/timer/tolerance)). `CGEventSource.secondsSinceLastEventType` needs no permission ([Apple](https://developer.apple.com/documentation/coregraphics/cgeventsource/secondssincelasteventtype(_:eventtype:))).
- **Spawned processes.** ActivityWatch calls per-poll `osascript` "undesirable from a performance standpoint" ([PR #52](https://github.com/ActivityWatch/aw-watcher-window/pull/52)).
- **Accessibility.** `AXIsProcessTrustedWithOptions` + `kAXTrustedCheckOptionPrompt`; the prompt is suppressed for sandboxed apps, effectively excluding the App Store ([Apple forums](https://origin-devforums.apple.com/forums/thread/24288), [Stack Overflow](https://stackoverflow.com/questions/74654210/sandbox-suppressing-accessibility-prompt)). Apple's own alert says the app can "control your Mac" and reach contacts/calendar ([Apple Support](https://support.apple.com/en-sg/guide/mac-help/mh43185/mac)), so the in-app explanation must pre-empt that.
- **Screen Recording.** Since 10.15 `CGWindowListCopyWindowInfo` omits `kCGWindowName` and zeroes `kCGWindowSharingState` without it ([Stack Overflow](https://stackoverflow.com/questions/56597221/detecting-screen-recording-settings-on-macos-catalina), [Ryan Thomson](https://www.ryanthomson.net/articles/screen-recording-permissions-catalina-mess/)); Apple calls that gating undocumented and steers to `CGPreflightScreenCaptureAccess`/ScreenCaptureKit ([Apple forums](https://developer.apple.com/forums/thread/839069)). Sequoia re-prompts monthly with no permanent allow ([MacRumors](https://www.macrumors.com/2024/08/15/macos-sequoia-screen-recording-app-permissions/), [15.1](https://www.macrumors.com/2024/10/07/apple-screen-recording-popup-update/)).
- **Refuse:** Screen Recording as a default path (Timing and Rize gate it behind opt-in); keystroke/content capture; title logging without an off switch (RescueTime has one); any network egress of titles/paths.

## Recommendations for Cutaway (ranked)

1. **Event-driven loop.** Keep the 1 Hz permission-free idle read; move app switches to `NSWorkspace.didActivateApplicationNotification` and Resolve titles to an `AXObserver` (`kAXFocusedWindowChanged` + `kAXTitleChanged`), with the 5 s poll as fallback (Apple guidance; ActivityWatch PR #68). Effort M. No new permission.
2. **Adobe project names via AppleScript.** AE `DoScript` → `app.project.file`; PS/AI `name of current document`; InDesign `full name of document 1`. Query on activation events only and cache (Timing's model). Effort M. **New permission: Automation, one prompt per app**, with RescueTime-style copy.
3. **Skip Premiere Pro, say so.** Empty dictionary (local sdef), title hidden from AX (Timing). A UXP panel is L; Screen Recording brings Sequoia's monthly nag — refuse. Effort S.
4. **Display-sleep-assertion exemption.** When input goes stale, treat the user as present if the frontmost anchor holds `PreventUserIdleDisplaySleep` (Timing's rule); cheaper than >50 % CPU and covers playback/review. Keep the 30-min cap. Effort S. No new permission.
5. **Prompt floor and ceiling.** Never ask under 5 min or after 10 h; return focus to the prior app on dismiss (Timing). Effort S.
6. **Resolve Tier 1 polish.** Use 21.0.3's `GetProjectAttributesInCurrentFolder()` to list projects without opening them; gate spawns on `scriptapp` non-None. Effort S. Studio only.
7. **Rule-based matching** on title/path with Timemator-style dwell before switching; offer a rule on project creation (Timing). Effort M. No new permission.
8. **Permission copy audit.** Accessibility = "reads window titles, never controls your Mac"; Automation = per-app project name; state "never Screen Recording, never keystrokes, nothing leaves your Mac". Effort S.

## Methodology

Exa (until rate-limited) and WebSearch on 2026-09-05; vendor help centers, Apple docs, Blackmagic PDFs and GitHub sources fetched directly. Preferred ≤18 months; older pages (Photoshop/Illustrator titles 2008–2012, Catalina permission threads 2019–2020, InDesign AppleScript 2013) kept only where behaviour is unchanged and flagged with dates. Adobe dictionaries verified locally with `sdef` on installed 2026 builds plus `NSAppleScriptEnabled` in each Info.plist; `fuscript` verified in the installed Resolve 21.0.4 bundle. The Blackmagic forum thread on `scriptapp` returning None returned HTTP 403 and was not used. Word count excludes Sources.
